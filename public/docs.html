GET /api/health Public

Check system health, database connection, and uptime.

POST /api/auth/register Public

Register a new attendee or organizer account.

POST /api/auth/login Public

Authenticate and receive a JWT Bearer token.

GET /api/auth/me Bearer Token Required

Fetch details of the currently authenticated user.

GET /api/events Public

List events with search filter, pagination, and real-time remaining seat counts.

GET /api/events/:id Public

Get single event details along with remainingSeats and registeredCount.

POST /api/events Organizer Token Required

Create a new event. Only users with role: "organizer" are authorized.

POST /api/events/:id/register Bearer Token Required

Register current logged-in user for an event. Prevents duplicate registrations and blocks if full.

GET /api/registrations/my Bearer Token Required

View all registrations belonging to the authenticated user with populated event details.

PATCH /api/registrations/:id/cancel Bearer Token Required

Cancel user's own registration. Frees up a seat immediately.

GET /api/events/:id/registrations Organizer Token Required

View the list of registered attendees for an event created by the organizer.
